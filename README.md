# 象限方塊 Quadrant Blocks

> 把每天的待辦丟進艾森豪四象限，做完一件就在對應顏色的方塊上填一格——一個把「優先順序」變得看得見的網頁小工具。

## 這是什麼

一個純前端的個人生產力工具。每天睡前把明天要做的事一件件丟進四個象限，隔天做完（或委派、刪除）就打勾，對應象限的方塊會照完成比例由下往上填色——**盤面本身就是一張會填滿的艾森豪矩陣**。

它想解決的不是「忘記做事」，而是：事情一多就**看不到進度、也分不清輕重**。用填色方塊把「我今天推進了多少、把力氣花在哪一區」變得一眼就懂。

## 四個象限

| 象限 | 意義 | 策略 | 顏色 |
|---|---|---|---|
| 立即完成 | 重要且緊急 | 立刻做，但儘量減少（避免長期高壓） | 🔴 紅 |
| 制定計劃 | 重要不緊急 | 投入最多時間（關鍵產出區） | 🔵 藍 |
| 委派 / 批次 | 緊急不重要 | 交給別人或批次處理 | 🟡 黃 |
| 刪除 / 限時 | 不重要不緊急 | 直接刪除或限制時間 | 🟢 綠 |

**一個小巧思**：如果某天紅色填滿、藍色空空，一眼就看出「今天都在救火、沒做到關鍵產出」——畫面本身在提醒你調整。

## 怎麼用

不需要安裝任何東西：

1. 下載或 clone 這個 repo
2. 用瀏覽器打開 `index.html`

就這樣。資料存在你自己的瀏覽器（localStorage），離線可用、不需要帳號、不會上傳到任何地方。

## 技術

- 純 HTML / CSS / JavaScript，**單一檔案、零相依套件**
- 資料持久化：瀏覽器 `localStorage`
- 響應式版面，支援深色 / 淺色主題
- 字體：IBM Plex Mono（數字/標籤）＋ Noto Sans TC（中文）

## 設計思路

這個工具的做法：**資料與畫面刻意分開**——任務清單是唯一的真相，畫面只負責把它算成填色（完成數 ÷ 總數 × 4 格）。這樣之後想改算法只動邏輯、想改外觀只動樣式，彼此不干擾。

完整的「問題 → 思考 → 設計 → 成果」放在 case study。
